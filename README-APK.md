# نشر تطبيق AST-2012A كـ APK تلقائيًا من GitHub

بعد إعداد مرة واحدة بس (تحت)، أي `push` جديد على فرع `main` هيعمل تلقائيًا:
1. نشر التطبيق كموقع PWA على GitHub Pages.
2. بناء ملف APK حقيقي موقّع من نفس الموقع (باستخدام Bubblewrap / Trusted Web Activity).
3. إنشاء **Release** جديد على GitHub مرفق فيه ملف الـ APK جاهز للتحميل والتثبيت.

---

## ⚠️ ليه فيه خطوة يدوية أول مرة؟

أي تطبيق أندرويد لازم يتوقّع بـ **مفتاح توقيع (signing key)** ثابت، عشان:
- أندرويد يسمح بتثبيت التحديثات فوق بعض (لو المفتاح اتغير، أي تحديث جديد هيتطلب من المستخدم يمسح التطبيق القديم الأول).
- GitHub (لأسباب أمنية) مش بيسمح بتخزين ملفات حساسة زي المفاتيح في الكود نفسه — بيتخزنوا في **Secrets** مشفّرة، وده محتاج منك تضيفهم بنفسك مرة واحدة.

بعد الخطوة دي، كل حاجة تلقائية 100%.

---

## خطوات الإعداد (تُعمل مرة واحدة فقط)

### 1) فعّل GitHub Pages بالـ Actions
اذهب إلى: **Settings → Pages → Source** واختر **GitHub Actions**.

### 2) ولّد مفتاح التوقيع
افتح **Codespace** على المستودع (أو أي جهاز عليه Java)، وشغّل:
```bash
bash scripts/generate-keystore.sh
```
هيطلب منك كلمة مرور (احفظها)، وفي الآخر هيطبعلك:
- قيمة `ANDROID_KEYSTORE_BASE64` (نص طويل)
- بصمة `SHA256` (هتحتاجها في الخطوة 4)

### 3) أضف الأسرار في GitHub
اذهب إلى: **Settings → Secrets and variables → Actions → New repository secret**
وأضف الأربعة دول:

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | الناتج من الخطوة اللي فوق |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة المرور اللي دخّلتها |
| `ANDROID_KEY_ALIAS` | `androidkey` |
| `ANDROID_KEY_PASSWORD` | نفس كلمة مرور الـ Keystore (إلا لو غيّرتها وقت الإنشاء) |

### 4) (اختياري لكن مستحسن) فعّل الوضع كامل الشاشة بدون شريط عنوان
افتح `.well-known/assetlinks.json` وحط بصمة الـ SHA256 اللي طلعتلك في الخطوة 2 بدل
`REPLACE_WITH_YOUR_SHA256_FINGERPRINT_AFTER_RUNNING_generate-keystore.sh`، واعمل `commit` و`push`.

### 5) push عادي
```bash
git add .
git commit -m "Setup APK release pipeline"
git push origin main
```

روح لتبويب **Actions** في المستودع، وهتلاقي الـ workflow شغال. بعد ما يخلص (حوالي 5-10 دقايق أول مرة)، هتلاقي **Release** جديد في تبويب **Releases** فيه ملف `.apk` جاهز للتحميل والتثبيت مباشرة على أي جهاز أندرويد.

---

## بعد كده؟
أي `push` جديد على `main` = نشر تلقائي + إصدار APK جديد تلقائيًا، من غير أي تدخل يدوي تاني.

## تثبيت التطبيق على الموبايل
1. حمّل ملف `.apk` من أحدث Release.
2. لو ظهرت رسالة "مصدر غير معروف"، فعّل السماح من إعدادات الأندرويد (مرة واحدة بس لكل مصدر).
3. ثبّت التطبيق عادي زي أي APK.

## استكشاف الأخطاء
- **الـ workflow فشل في خطوة "تحقق من وجود أسرار التوقيع"** → لسه ما ضفتش الأسرار (الخطوة 3 فوق).
- **فشل في "انتظار جاهزية الموقع"** → تأكد إن GitHub Pages مفعّل فعليًا بـ Source = GitHub Actions.
- **عايز تغيّر اسم التطبيق أو الحزمة (Package ID)** → عدّل `packageId` و`name` و`launcherName` في `twa-manifest.template.json`.
