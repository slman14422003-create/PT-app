# نشر تطبيق AST-2012A كـ APK تلقائيًا من GitHub

## الوضع الافتراضي: ارفع الملفات وخلاص

من غير أي إعداد إضافي، أي `push` على فرع `main` هيعمل تلقائيًا:
1. نشر التطبيق كموقع PWA على GitHub Pages.
2. بناء ملف APK حقيقي موقّع (باستخدام Bubblewrap / Trusted Web Activity).
3. إنشاء **Release** جديد على GitHub مرفق فيه ملف الـ APK جاهز للتحميل والتثبيت.

**الخطوة الوحيدة المطلوبة منك قبل أول push:**
اذهب إلى **Settings → Pages → Source** واختر **GitHub Actions**. (خطوة مرة واحدة، دقيقة واحدة، ومش هتتكرر تاني).

بعد كده push عادي:
```bash
git add .
git commit -m "نشر التطبيق"
git push origin main
```
روح لتبويب **Actions**، استنى شوية (5-10 دقايق أول مرة)، وهتلاقي **Release** جديد في تبويب **Releases** فيه ملف `.apk` جاهز.

---

## ⚠️ ملاحظة مهمة: تحديث التطبيق لاحقًا

بدون إعداد إضافي، كل مرة تعمل فيها `push` هيتولّد **مفتاح توقيع جديد تلقائيًا** لكل إصدار.
هذا معناه: لو نزّلت تحديث جديد وعندك النسخة القديمة مثبتة على موبايلك، أندرويد هيرفض التثبيت
فوقها مباشرة (لازم تمسح القديمة الأول ثم تثبّت الجديدة). هذا طبيعي وغير ضار، بس لو حابب
تتفادى الموضوع ده وتخلي التحديثات تركب فوق بعض زي أي تطبيق عادي، اعمل الإعداد الاختياري تحت
**مرة واحدة بس**.

---

## إعداد اختياري: مفتاح توقيع ثابت (لتحديثات سلسة بدون حذف)

### 1) ولّد مفتاح التوقيع
افتح **Codespace** على المستودع (أو أي جهاز عليه Java)، وشغّل:
```bash
bash scripts/generate-keystore.sh
```
هيطلب منك كلمة مرور (احفظها)، وفي الآخر هيطبعلك:
- قيمة `ANDROID_KEYSTORE_BASE64` (نص طويل)
- بصمة `SHA256` (هتحتاجها في الخطوة 3)

### 2) أضف الأسرار في GitHub
اذهب إلى: **Settings → Secrets and variables → Actions → New repository secret**
وأضف الأربعة دول:

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | الناتج من الخطوة اللي فوق |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة المرور اللي دخّلتها |
| `ANDROID_KEY_ALIAS` | `androidkey` |
| `ANDROID_KEY_PASSWORD` | نفس كلمة مرور الـ Keystore |

من اللحظة دي، الـ workflow هيكتشف وجود المفتاح تلقائيًا ويستخدمه بدل ما يولّد واحد مؤقت — من غير أي تعديل تاني على الكود.

### 3) (اختياري) فعّل الوضع كامل الشاشة بدون شريط عنوان
افتح `.well-known/assetlinks.json` وحط بصمة الـ SHA256 اللي طلعتلك في الخطوة 1 بدل
`REPLACE_WITH_YOUR_SHA256_FINGERPRINT_AFTER_RUNNING_generate-keystore.sh`، واعمل `commit` و`push`.

---

## تثبيت التطبيق على الموبايل
1. حمّل ملف `.apk` من أحدث Release.
2. لو ظهرت رسالة "مصدر غير معروف"، فعّل السماح من إعدادات الأندرويد (مرة واحدة بس لكل مصدر).
3. ثبّت التطبيق عادي زي أي APK.

## استكشاف الأخطاء
- **فشل في "انتظار جاهزية الموقع"** → تأكد إن GitHub Pages مفعّل فعليًا بـ Source = GitHub Actions.
- **عايز تغيّر اسم التطبيق أو الحزمة (Package ID)** → عدّل `packageId` و`name` و`launcherName` في `twa-manifest.template.json`.
- **عايز رقم إصدار مختلف** → الرقم بيتولد تلقائيًا من رقم تشغيل الـ workflow، مفيش داعي تلمسه.
